二阶欧拉常微分方程与特征根 β, α：实物期权最常见的“八股文”

1. 3 分钟直觉唤醒（一句话核心）

实物期权里几乎所有等待区域的价值函数都满足同一个二阶欧拉方程，只要试探解 V(x) = x^γ，微分方程瞬间退化成初中一元二次方程，解出正根 β > 1 和负根 α < 0。

它解决什么建模痛点：你看到顶刊论文满屏的 β、α、A x^β + B x^α 时不用再发怵：它们不是凭空冒出来的神秘常数，而是同一个二阶欧拉 ODE 的两个基本解，所有连续时间实物期权模型几乎都共用这套骨架。

课程衔接：把 RO-S01 的幂函数求导直接代入微分方程，这是跨入第 1 层功力的核心钥匙。

2. 10 分钟核心公式与白话拆解

在等待区，期权价值 V(x) 必须满足无套利/动态规划平衡：折现要求 r V(x) 等于漂移项带来的增值 μ x V'(x) 加上波动项带来的凸性收益 (1/2)σ² x² V''(x)。

观察这个方程的神奇对称性：V'' 前面乘着 x²，V' 前面乘着 x，V 前面乘着 1。每求一次导降一次幂，再乘以对应次数的 x，幂次竟然完全恢复原样！

因此试探解 V(x) = x^γ 代进去，x^γ 可以整项约掉，瞬间变成关于 γ 的二次方程 Q(γ) = (1/2)σ² γ(γ-1) + μγ - r = 0。只要折现率 r > μ（避免现值发散），这条开口向上的抛物线必然穿过 γ 轴两次：一个正根 β > 1，一个负根 α < 0。

实物期权核心二阶欧拉方程（齐次）
$$\frac{1}{2}\sigma^2 x^2 V''(x) + \mu x V'(x) - r V(x) = 0$$

白话读法：波动率带来的二阶凸性项 + 趋势漂移带来的一阶项 - 资金时间成本 rV = 0。

特征二次方程与通解
$$Q(\gamma) = \frac{1}{2}\sigma^2 \gamma(\gamma-1) + \mu \gamma - r = 0 \implies V(x) = A x^\beta + B x^\alpha \quad (\beta > 1,\; \alpha < 0)$$

白话读法：通解是两个幂函数的线性组合。若 x → 0 时等待期权应归零（市场彻底枯竭时不会有无穷大价值），就必须令 B = 0，只保留 A x^β；若考虑退出/放弃期权（x 越低越值钱），则往往令 A = 0 保留 B x^α。

第 1 步：代入试探解 V(x) = x^γ

x V'(x) = γ x^γ，x² V''(x) = γ(γ-1) x^γ。代入方程并提出公因子 x^γ > 0，立即得到 Q(γ) = 0。

实战口诀：以后看到 x²V'' + c1 xV' + c2 V = 0，零犹豫直接设 V = x^γ。
适用边界：仅适用于系数是 x², x, 1 结构的欧拉方程（来自几何布朗运动 GBM）；若是算术布朗运动（ABM），试探解是 e^{γx}。

第 2 步：不背求根公式，直接画 Q(γ) 抛物线判根的位置

计算三个关键点：Q(0) = -r < 0；Q(1) = μ - r < 0（因为假设 r > μ）；且 γ → ±∞ 时 Q(γ) → +∞。由连续性，抛物线必在 (1, +∞) 有唯一根 β > 1，在 (-∞, 0) 有唯一根 α < 0。

实战口诀：画草图检查 Q(0) 和 Q(1) 的符号，10 秒就能记住 β > 1 和 α < 0，永远不会记反。
适用边界：必须满足无泡沫条件 r > μ；若 r ≤ μ，Q(1) ≥ 0，说明不投资一直等下去现值发散，最优停止问题退化。

第 3 步：用边界行为删掉多余项

对投资进入期权：当 x → 0+ 时，x^α → +∞（因为 α < 0），这在经济上不可能，因此必须令 B = 0。对有上下双边界（如反射边界 + 投资门槛）的问题，A 和 B 都要保留。

实战口诀：看到“无下限且 x→0 时价值归零”，删 B x^α；看到“有下限保证/反射边界”，两项都要留。
适用边界：不要机械删掉 B x^α！像 B003 这类带下限或反射机制的模型，B x^α 项恰恰承载了下限保护的价值。

3. 5 分钟最小算例（教学演示）

【教学演示】手算一组干净参数的特征根 β 与 α

（教学演示算例）设折现率 r = 0.06，漂移率 μ = 0.02，波动率 σ = 0.20（因此 (1/2)σ² = 0.02）。

  1. 写出特征方程：0.02 γ(γ-1) + 0.02 γ - 0.06 = 0。
  2. 化简：0.02 γ² - 0.02 γ + 0.02 γ - 0.06 = 0，即 0.02 γ² = 0.06，得 γ² = 3。
  3. 解出两个根：β = √3 ≈ 1.732 > 1，α = -√3 ≈ -1.732 < 0。对应的经典投资期权倍数 β/(β-1) ≈ 1.732 / 0.732 ≈ 2.366，意味着项目现值要达到成本的 2.37 倍才值得立刻动手。

4. 3 分钟防坑边界与常见误区

顶刊与推导避坑提示
  • 把 r > μ 当成可有可无的角落假设：一旦 μ ≥ r，等待的预期增长快过折现，项目永远值得继续等下去，不存在有限最优投资门槛。
  • 死记“B 永远等于 0”：只有在状态可以一路跌向 0 且无下限保护时才令 B = 0；一旦引入放弃期权、最低收益保障或反射边界，B x^α 必须保留。

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 为什么在 r > μ > 0 且 σ > 0 时，特征方程 Q(γ) = (1/2)σ²γ(γ-1) + μγ - r = 0 一定满足 β > 1 且 α < 0？
展开参考答案与解析

参考答案：因为 Q(γ) 是开口向上的二次函数，且 Q(0) = -r < 0、Q(1) = μ - r < 0，所以两个零点必然分别落在 0 的左侧（α < 0）和 1 的右侧（β > 1）。

解析：利用介值定理和抛物线开口向上，无需解求根公式即可严格锁定两根位置。

常见失误：强行去背复杂的求根公式，结果在比较静态或考试推导时记错正负号。

Q2. 当波动率 σ 增大时，正特征根 β 是变大还是变小？用抛物线 Q(γ) 直观解释。
展开参考答案与解析

参考答案：β 严格变小（向 1 靠近）。

解析：在 γ = β > 1 处，β(β-1) > 0。当 σ 增大时，(1/2)σ²γ(γ-1) 变大，整条抛物线在 γ > 1 区域向上抬起，与横轴的交点 β 必然向左移动（变小）。

常见失误：凭感觉认为“波动越大，指数 β 越大”，实际上 β 变小才会让期权倍数 β/(β-1) 变大。

Q3. 如果投资项目除了“未来择机建厂”外，还拥有一个“政府保底价下限”机制，通解 V(x) = A x^β + B x^α 中的 B 还能直接设为 0 吗？
展开参考答案与解析

参考答案：不能。

解析：因为有了下限边界，x 不会无限制趋近于 0，B x^α 项在边界附近有限且恰好用来刻画下限保护带来的额外价值。

常见失误：把单边界入门题的结论直接套用到带反射边界或保底条款的模型里。

60 秒闭卷费曼复述

不看求根公式，只画一条抛物线 Q(γ)，在 60 秒内讲清楚为什么 β > 1、α < 0 以及为什么 σ 越大 β 越小。
