凸分析判号与代数变形套路：构造 U 型函数 G(z) 与倒推法

1. 3 分钟直觉唤醒（一句话核心）

顶刊定理里看起来神来之笔的“构造凸函数 G(z) 判号”，背后其实有一套固定的降维套路：无量纲化比值 z → 消掉参数 → 求导看凸性 → 用数值画图先验真再倒推。

它解决什么建模痛点：拆解第 3 层最吃灵气的代数不等式构造（如比较两个隐式门槛 b_R 与 b_C 的大小），告诉你研究者真实的工作流。

课程衔接：呼应 RO-S01 的凸函数性质，并自然引出 Stage 4 的 SymPy 与数值探索。

骨架预览提示：本节当前提供核心公式、学习定位与预热自测；后续逐阶段精修时将补齐详细白话拆解、完整教学演示算例与更多自测题。

2. 10 分钟核心公式与白话拆解

【骨架预览 · 待后续精修】本课拆解如何把双门槛比较问题化为在 b_C 处判断另一门槛方程 H_R(b_C) 的符号，再通过变量替换 z = b_C / a 消去尺度参数，寻找单调或 U 型辅助函数。

门槛排序判号的通用转化
$$H_R(b_R) = 0,\; H_R'(b) > 0 \implies \Big(b_R > b_C \iff H_R(b_C) < 0\Big)$$

白话读法：想比较两个都解不出来的隐式根 b_R 和 b_C，不用解它们：只需把 b_C 代进 H_R，再把 H_C(b_C)=0 代换消元，最后判一个单变量函数 G(z) 的正负号！

待精修：研究者真实工作流

先用 Python 扫参画图确认结论成立 → 寻找无量纲比值 z 降维 → 反复乘除正因子把复杂项凑成单调或凸函数。

实战口诀：永远先数值画图确认符号方向，再动手凑解析证明。
适用边界：当全局符号确实不唯一（存在反例区域）时，应转向 Stage 4 的局部存在性 + 区间算术证明。

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 【预热自测】已知 H_R(b) 严格递增且 H_R(b_R) = 0，若能证明 H_R(b_C) < 0，则 b_R 和 b_C 谁更大？
展开参考答案与解析

参考答案：b_R > b_C。

解析：因为 H_R 严格递增，H_R(b_C) < 0 = H_R(b_R) 立即推出 b_C < b_R。

常见失误：忘记先确认 H_R 是递增还是递减，导致结论正好相反。
