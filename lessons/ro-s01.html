导数、弹性与二阶曲率：给平滑粘贴和凸性判号打底

1. 3 分钟直觉唤醒（一句话核心）

一阶导数告诉你“多涨一点值多少钱”（斜率），二阶导数告诉你“斜率是不是越涨越快”（弯曲方向），而弹性把它们变成无量纲的百分比倍数。

它解决什么建模痛点：实物期权里反复出现两件核心事：一是在投资门槛处要求价值曲线“平滑相切”（用到一阶导数相等），二是判断等待价值为何随波动率上升而增加、以及证明辅助函数有唯一零点（全靠二阶导数决定凸性）。

课程衔接：这是整个 8 周计划的起点：先用 20 分钟把大学微积分里最常用的三个概念与期权图像绑定起来。

2. 10 分钟核心公式与白话拆解

把一个项目的价值函数 V(x) 想象成一条随市场需求 x 变化的山坡。一阶导数 V'(x) 是你脚下的坡度：需求 x 每多 1 单位，项目价值大概多 V'(x)。

二阶导数 V''(x) 是坡度的变化率，也就是“弯不弯”。如果 V''(x) > 0，山坡向上弯（像开口向上的碗，称为凸函数）：市场好时你赚得越来越快，市场差时你跌得越来越慢，这就是期权“下有底、上不封顶”的几何形状。

弹性 η = x V'(x) / V(x) 回答“需求涨 1%，价值涨百分之几”。幂函数 V(x) = A x^β 的弹性恒等于常数 β——这正是后面欧拉方程总爱长成 A x^β 的根本原因。

幂函数的导数与弹性
$$V(x) = A x^\beta \implies V'(x) = \beta A x^{\beta-1},\quad V''(x) = \beta(\beta-1) A x^{\beta-2},\quad \frac{x V'(x)}{V(x)} = \beta$$

白话读法：当价值函数是幂函数 A x^β（其中 A>0, x>0）时，每求一次导就掉下来一个系数并降一次幂；当 β > 1 时，β(β-1) > 0，说明函数严格向上弯曲（严格凸），且它的弹性处处等于 β。

凸函数的切线在下性质
$$V''(x) > 0 \implies V(y) \ge V(x) + V'(x)(y - x)$$

白话读法：开口向上的光滑函数，图像永远在任意一点切线的上方。后续 Stage 3 用凸函数判号、Stage 2 验证等待价值大于立即执行价值，底层靠的都是这条几何性质。

第 1 步：把“边际增量”写成一阶导数

市场状态从 x 变为 x + Δx，价值变化 ΔV ≈ V'(x)Δx。在最优停止门槛 x* 处，如果再等一丁点带来的边际收益不等于立刻行动的边际收益，就说明 x* 还能调得更好。

实战口诀：见到 V'(x*) = 立即行动收益的导数，立刻反应这是“斜率相切”。
适用边界：函数在 x* 处必须可微；有尖角（折点）的地方不能直接写 V'(x*)。

第 2 步：用二阶导数识别“期权凸性”

对 V(x) = A x^β 求两次导得到 V''(x) = β(β-1) A x^{β-2}。只要 A > 0 且 β > 1，就有 V''(x) > 0，图形严格向上弯。

实战口诀：以后看到 β > 1 且系数为正，心里立刻画出一个向上弯曲的期权价值曲线。
适用边界：如果 0 < β < 1，则 β(β-1) < 0，函数反而是凹的（边际递减）。

第 3 步：用弹性读懂比例关系

在最优门槛处常见条件 x* V'(x*) = β V(x*)，把 x* 移过去就是弹性等于 β。这个关系能让你一眼消掉未知常数 A。

实战口诀：消元技巧：用 V'(x)/V(x) = β/x 可以直接绕开待定系数 A。
适用边界：仅对单项幂函数 A x^β 成立；若有两项 A x^β + B x^α，弹性不再是常数。

3. 5 分钟最小算例（教学演示）

【教学演示】幂函数期权价值的斜率与凸性检查

（教学演示算例）假设某待建光伏项目的等待期权价值写成 V(x) = 2 x^2（这里 A = 2, β = 2），而立即投资的净收益是 x - 1（直线，斜率恒为 1）。

  1. 求一阶导数：V'(x) = 4x；立即投资收益的导数为 1。
  2. 求二阶导数：V''(x) = 4 > 0，说明等待价值严格向上弯曲（严格凸）。
  3. 找两者斜率相等的点：令 4x = 1，得 x = 0.25；但此时 V(0.25) = 0.125，而立即收益是 0.25 - 1 = -0.75，说明常数 A = 2 并不是从自由边界解出来的——在 Stage 2 里，A 和 x* 会通过“值相等 + 斜率相等”一起解出来。

4. 3 分钟防坑边界与常见误区

顶刊与推导避坑提示
  • 把“V'(x) > 0（单调递增）”和“V''(x) > 0（凸函数）”混为一谈：直线 y = 2x 也单调递增，但它没有凸性（V'' = 0），也就没有波动率带来的期权溢价。
  • 误以为 V''(x) > 0 就一定有最小值点：像 V(x) = x^2 在 x > 0 上处处递增且严格凸，在开区间 (0, ∞) 上并没有内部极小值，必须结合一阶导数是否变号来判断。

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 对于函数 V(x) = A x^β（A > 0, x > 0），β 满足什么条件时，V(x) 既是递增的又是严格凸的？
展开参考答案与解析

参考答案：β > 1。

解析：一阶导数 β A x^{β-1} > 0 需要 β > 0；二阶导数 β(β-1) A x^{β-2} > 0 需要 β > 1 或 β < 0。两者取交集得 β > 1。

常见失误：漏掉 β > 1 的要求，误写成 β > 0（当 0 < β < 1 时函数递增但为凹函数）。

Q2. 为什么说“弹性等于常数 β”在解实物期权门槛时特别好用？
展开参考答案与解析

参考答案：因为 x V'(x) / V(x) = β 会把待定系数 A 自动约掉，可以直接把值匹配和平滑粘贴合并成一个只含门槛 x* 的方程。

解析：当等待价值只有单项 A x^β 时，V(x*) 和 V'(x*) 都正比于 A，两式相除立刻消去 A。

常见失误：在含有两项 A x^β + B x^α 的双边界问题里也直接套用单项弹性公式。

Q3. 如果某辅助函数 G(z) 在区间 (0, ∞) 上满足 G''(z) > 0，且 G(0+) > 0、G(1) = 0、G'(1) < 0，它在 (0, 1) 内可能有零点吗？
展开参考答案与解析

参考答案：不可能。

解析：因为 G 是严格凸函数，它的导数 G'(z) 严格递增。既然 G'(1) < 0，那么在所有 z < 1 处都有 G'(z) < G'(1) < 0，即 G 在 (0, 1] 上严格递减，从正数一路降到 G(1) = 0，因此 (0, 1) 内恒正。

常见失误：只看两端点符号而不结合导数单调性，误以为 U 型曲线一定先降后升。
