布朗运动与几何布朗运动（GBM）：连续时间模型的通用发动机

1. 3 分钟直觉唤醒（一句话核心）

布朗运动 W_t 是“处处连续但处处锯齿不可微”的随机游走极限，它的关键铁律是 (dW_t)² = dt；几何布朗运动 dX_t/X_t = μ dt + σ dW_t 则是把这种随机震荡写成百分比收益率。

它解决什么建模痛点：90% 的实物期权论文第 2 节第一行都是“假设状态变量 X_t 服从几何布朗运动 dX_t = μ X_t dt + σ X_t dW_t”。今天彻底看懂每一项的物理含义和 (dW_t)² = dt 的直觉，你就能无缝进入 Stage 2 搭模型。

课程衔接：Stage 1 的收官课：把前 5 课的导数、ODE、折现和对数正态，全部装配到连续时间随机过程上。

2. 10 分钟核心公式与白话拆解

想象你在抛硬币走路：每经过极短时间 Δt，你往前或往后随机迈一步，步长不是 Δt，而是 √Δt（因为独立增量的方差与时间 Δt 成正比，所以标准差是 √Δt）。当 Δt → 0，这条密密麻麻的锯齿轨迹就是标准布朗运动 W_t。

正因为步长量级是 √Δt，把它平方之后，(ΔW_t)² 的量级竟然直接等于 Δt（而不是高阶小量 (Δt)²）！这就是普通微积分里没有、但随机微积分里核心的铁律：(dW_t)² = dt。

如果把布朗运动直接当价格，价格可能跌成负数；所以经济与金融里改写相对变化率 dX_t / X_t = μ dt + σ dW_t（即几何布朗运动 GBM），保证价格永远大于 0，且涨跌幅度按百分比缩放。

几何布朗运动（GBM）的随机微分方程（SDE）
$$dX_t = \mu X_t \, dt + \sigma X_t \, dW_t,\quad X_0 = x > 0$$

白话读法：瞬时价格变动 = 确定性趋势项（μ X_t dt）+ 随机波动冲击项（σ X_t dW_t）。两边同除以 X_t 就是百分比收益率 dX_t/X_t = μ dt + σ dW_t。

随机微积分乘法规则表（Itô 速查口诀）
$$(dt)^2 = 0,\quad dt \cdot dW_t = 0,\quad (dW_t)^2 = dt$$

白话读法：在展开二阶 Taylor 级数时，所有含 (dt)² 和 dt·dW_t 的项都比 dt 小得多可以扔掉，唯独 (dW_t)² 留了下来并变成确定性的 dt。

第 1 步：记住布朗运动 W_t 的 3 条核心特征

① W_0 = 0；② 独立增量：未来一段 ΔW = W_{t+Δt} - W_t 与过去历史完全无关（马尔可夫性）；③ 正态增量：W_{t+Δt} - W_t ~ N(0, Δt)。

实战口诀：因为增量与历史无关，最优决策只取决于当前状态 X_t，不取决于怎么走过来的。
适用边界：真实市场常有跳跃或均值回归，GBM 是最干净的基准模型，用来抓住核心机制。

第 2 步：理解为什么 (dW_t)² = dt

ΔW_t = √Δt · ε（其中 ε ~ N(0,1)），所以 (ΔW_t)² = Δt · ε²。它的期望是 Δt，而把很多个小段加起来时随机误差按 √Δt 消掉，最终变成确定性的 dt。

实战口诀：这是 Stage 2 推导 Itô 引理的唯一“黑魔法”，今天看懂了，下周 5 分钟就能学会 Itô 引理。
适用边界：严格数学上这是均方收敛（二次变差 [W, W]_t = t），不是逐点普通导数。

第 3 步：连接离散模拟步（预告 Stage 4 代码）

在电脑里模拟 GBM 路径有两种方式：精确对数步 X_{t+Δt} = X_t exp((μ - ½σ²)Δt + σ√Δt · ε)，或欧拉近似步 X_{t+Δt} ≈ X_t + μ X_t Δt + σ X_t √Δt · ε。对 GBM 优先用精确对数步，永不出现负价格。

实战口诀：写代码模拟 GBM 时，标准正态随机数 ε 一定要乘以 √Δt，绝不能乘以 Δt。
适用边界：离散化步长 Δt 太大时会漏掉路径在步长中间穿越门槛的情况（离散监控偏差）。

3. 5 分钟最小算例（教学演示）

【教学演示】计算一步离散时间里的 GBM 涨跌幅度

（教学演示算例）设当前市场需求 X_0 = 100，μ = 0.04，σ = 0.20，时间步长 Δt = 0.01 年（约 2.5 个交易日），抽到一个标准正态冲击 ε = +1.5。

  1. 先算时间步长的平方根：√Δt = √0.01 = 0.10。
  2. 确定性对数漂移：(μ - ½σ²)Δt = (0.04 - 0.02) × 0.01 = +0.0002（非常小）。
  3. 随机冲击项：σ √Δt · ε = 0.20 × 0.10 × 1.5 = +0.03（比漂移项大 150 倍！）。于是 X_{0.01} = 100 × exp(0.0302) ≈ 103.07。这直观解释了为什么在短时间尺度上，随机波动的量级 √Δt 远压过趋势项 Δt。

4. 3 分钟防坑边界与常见误区

顶刊与推导避坑提示
  • 在写模拟或手算增量时把 σ√Δt 写成 σΔt：这会导致波动率随着步长变细而彻底消失。
  • 误以为 GBM 路径是光滑可导的：如果路径可导，(dW_t)² 就会是 (dt)² = 0，那么 Itô 引理里的二阶项 ½σ²x²V'' 会消失，整个实物期权的波动率价值也会跟着消失！

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 在极短时间 Δt 内，布朗运动增量 ΔW_t 的典型大小（标准差）与 Δt 是什么关系？为什么这导致 (dW_t)² = dt？
展开参考答案与解析

参考答案：标准差是 √Δt，因此平方 (ΔW_t)² 的量级恰好是一阶项 Δt，而不是可忽略的高阶小量 (Δt)²。

解析：因为 ΔW_t ~ N(0, Δt)，其方差就是 Δt。

常见失误：按普通微积分直觉把所有平方项都直接扔掉。

Q2. 为什么实物期权模型通常用几何布朗运动（GBM）而不是算术布朗运动（ABM）来刻画产品价格或市场需求？
展开参考答案与解析

参考答案：GBM 保证状态变量严格为正，且变化幅度按百分比缩放，更符合价格与需求的经济直觉，同时其对应的 ODE 是可解析求解的欧拉方程。

解析：ABM 允许状态变量跌为负数，更适合刻画可正可负的利润差或利率利差。

常见失误：不区分状态变量的正负域就随意选用随机过程。

Q3. 用一句话说明：如果把 (dW_t)² = dt 从数学世界里删掉，对实物期权建模会发生什么？
展开参考答案与解析

参考答案：ODE 里的波动率二阶项 ½σ²x²V'' 会消失，退化为确定性模型，等待期权因不确定性产生的额外价值也就无从谈起。

解析：波动率正是通过 (dW_t)² = dt 和价值函数的凸性 V'' > 0 一起进入模型并产生期权溢价的。

常见失误：把 (dW_t)² = dt 当成纯数学奇技淫巧，没看出它就是期权凸性溢价的发动机。
