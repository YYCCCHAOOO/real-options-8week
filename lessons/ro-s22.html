1. 3 分钟直觉唤醒（一句话核心）

普通浮点数有舍入误差不能当数学证明；区间算术（mpmath.iv）把每一步舍入误差都严丝合缝包进上下界里，配合介值定理与隐函数定理就能给出顶刊认可的严格存在性证书。

它解决什么建模痛点：看懂 B003 的 Theorem 3 这类“纯手算证明不了全局符号，但用区间算术把局部存在性证死”的现代顶刊证明技术。

课程衔接：直接呼应 RO-S02 的隐函数定理前提 H(x_0, θ_0)=0 且 H_x ≠ 0。

骨架预览提示：本节当前提供核心公式、学习定位与预热自测；后续逐阶段精修时将补齐详细白话拆解、完整教学演示算例与更多自测题。

2. 10 分钟核心公式与白话拆解

【骨架预览 · 待后续精修】本课介绍 Python `mpmath.iv`（区间算术）的基本原理：如何用严格包络区间证明 f(a) < 0 < f(b) 且 f'(x) 不含 0，从而得到无可辩驳的零点存在唯一性证书。

区间算术存在性证书条件
$$\sup F([a,a]) < 0 < \inf F([b,b]),\qquad 0 \notin F'([a,b])$$

白话读法：只要区间计算严格输出左端上界小于 0、右端下界大于 0，且导数区间不包含 0，就 100% 严格证明 [a, b] 内存在唯一根且满足隐函数定理条件。

待精修：区间证书 3 步写法

设高精度（如 50 位小数）→ 用 iv.mpf 构造输入区间 → 断言符号分离并导出可复现证书 JSON/日志。

实战口诀：用于证明存在性、局部比较静态或反例构造，堵死“浮点误差”质疑。
适用边界：区间算术适合证明具体参数点或紧致小盒上的性质，不能直接替代无界全参数空间的解析证明。

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 【预热自测】为什么 `mpmath.iv` 的区间算术结果可以作为严格数学证明，而普通 NumPy 浮点计算只能算数值证据？
展开参考答案与解析

参考答案：因为区间算术在每次加减乘除和初等函数运算时采用向外舍入，保证真实数学值严格落在输出区间内，彻底消除了舍入误差不确定性。

解析：因此一旦区间严格不含 0，符号结论就是数学定理级别的。

常见失误：以为只是把小数位数调高到 50 位就算区间证明（高精度浮点仍需区间包络才构成严格界）。

60 秒闭卷费曼复述

向合作者解释：区间算术怎么和介值定理、隐函数定理配合，把一个“看起来对”的数值例子变成严格定理。
