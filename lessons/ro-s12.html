反射边界与下限保证（Floor Guarantee）的标准组件组装

1. 3 分钟直觉唤醒（一句话核心）

当状态变量存在下限反射或政府保底补贴时，通解里必须同时保留 A x^β 和 B x^α 两项，用下边界的平滑/反射条件把组件拼进整篇论文。

它解决什么建模痛点：直接对接 B003 级别论文中常见的“反射过程（Reflecting GBM）”与“收益下限保证（Revenue Floor）”，看懂为什么装机价值 v_R(x) 和 v_C(x) 会多出幂函数调整项。

课程衔接：为 Stage 3 的局部时 Neumann 条件和 B003 论文对比结构做好铺垫。

骨架预览提示：本节当前提供核心公式、学习定位与预热自测；后续逐阶段精修时将补齐详细白话拆解、完整教学演示算例与更多自测题。

2. 10 分钟核心公式与白话拆解

【骨架预览 · 待下轮精修】本课对比“价格托底补贴（Cash-flow floor）”与“需求反射壁（Reflecting barrier）”两种常见组件的 ODE 解法与系数 B 的经济学含义。

带下限组件的标准现值结构
$$v(x) = \frac{x}{r - \mu} + B x^\alpha \quad (x \ge \underline{x},\; \alpha < 0)$$

白话读法：在高于下限的区域，价值 = 无干预永续现值 + 下限保护带来的看跌期权式增值 B x^α。

待精修：反射边界的边界条件 V'(a) = 0

在反射下界 a 处施加一阶导数为零（Neumann 条件），立刻解出系数 B。

实战口诀：识别论文里的“标准积木块”，不要每次从零发明。
适用边界：反射过程与分段收益下限的底层机制不同，不能混用边界条件（B003 的核心切口之一）。

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 【预热自测】在状态过程下界反射模型中，x > a 区域的现值公式为何保留 x^α（α < 0）而舍弃 x^β（β > 1）？
展开参考答案与解析

参考答案：因为当 x → +∞ 时，下界反射几乎不再触发，保护价值应趋于 0；只有 α < 0 的 x^α 满足 x → +∞ 时归零，而 x^β 会发散。

解析：无穷远增长条件（无泡沫条件）决定舍去发散项。

常见失误：记混 α 和 β 在 x → 0 与 x → ∞ 时的极限行为。
