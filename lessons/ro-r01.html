2. 10 分钟核心公式与白话拆解

回看这 2 周，你并没有去刷厚厚的考研高数题海，而是精准拿下了连续时间建模真正反复调用的 6 个零件。

零件之间是互相咬合的：GBM 的 (dW_t)² = dt 会在下周通过 Itô 引理生出二阶项 ½σ²x²V''，这就立刻变成你已经会解的欧拉方程 Q(γ) = 0；解出的 β > 1 保证 V(x) = A x^β 严格凸；已建成项目的永续现值是特解 x/(r-μ)；而任何没有闭式解的门槛单调性，你已经会用隐函数公式 dx*/dθ = -H_θ / H_x 去判号。

如果你能独立答对下面 5 道综合题里的 4 道，Stage 1 就已经稳稳过关，可以直接开 Stage 2！

Stage 1 核心公式总览表
$$\text{① } \frac{dx^*}{d\theta} = -\frac{H_\theta}{H_x} \qquad \text{② } Q(\gamma) = \frac{1}{2}\sigma^2\gamma(\gamma-1)+\mu\gamma-r=0 \qquad \text{③ } v_p(x)=\frac{x}{r-\mu} \qquad \text{④ } (dW_t)^2=dt$$

白话读法：记住这 4 个核心公式和它们的直觉画面，就拿下了 Stage 1 的全部精华。

3. 5 分钟最小算例（教学演示）

【教学演示】一口气串联 Stage 1 全部 6 课的微缩推演

（教学演示算例）设需求 X_t 服从 GBM（r=0.06, μ=0.02, σ=0.20），投资成本 I = 100。

  1. 由 RO-S04：建成后永续现值为 V_proj(x) = x / (0.06 - 0.02) = 25x。
  2. 由 RO-S03：特征根 β = √3 ≈ 1.732，等待价值设为 A x^β（严格凸，RO-S01）。
  3. 提前预告 Stage 2：令等待价值和净收益 25x - 100 在门槛 x* 处值相等且斜率相等，立刻解出 25 x* = (β/(β-1)) × 100 ≈ 236.6，即 x* ≈ 9.46（远高于静态 NPV=0 的盈亏点 x=4）！

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 【综合 1】若等待期权 V(x) = A x^β（A > 0, β > 1），它的斜率和弯曲方向分别是什么？
展开参考答案与解析

参考答案：斜率 V'(x) > 0（递增），二阶导 V''(x) > 0（严格向上弯曲/严格凸）。

解析：RO-S01 核心结论。

常见失误：漏掉 β > 1 对严格凸性的决定作用。

Q2. 【综合 2】某门槛方程 H(x*, r) = 0 满足 H_x > 0 且 H_r > 0，则折现率 r 升高时 x* 怎么变？
展开参考答案与解析

参考答案：x* 严格下降（dx*/dr = -H_r / H_x < 0）。

解析：RO-S02 隐函数比较静态公式。

常见失误：漏掉负号。

Q3. 【综合 3】写出 r = 0.08, μ = 0.04, σ = 0.20 时欧拉方程的特征二次方程，并判断两根所在区间。
展开参考答案与解析

参考答案：0.02 γ(γ-1) + 0.04 γ - 0.08 = 0（即 γ² + γ - 4 = 0），正根 β = (-1+√17)/2 ≈ 1.56 > 1，负根 α = (-1-√17)/2 ≈ -2.56 < 0。

解析：RO-S03 特征方程与抛物线判根。

常见失误：展开 γ(γ-1) 时漏掉 -γ 项。

Q4. 【综合 4】在 GBM 中，为什么 E[X_t] = x e^{μt} 但 ln(X_t/x) 的均值是 (μ - ½σ²)t？
展开参考答案与解析

参考答案：因为指数函数严格凸，E[exp(σW_t)] = exp(½σ²t) > 1，必须减去 ½σ²t 才能使算术期望保持 x e^{μt}。

解析：RO-S05 对数正态均值与波动率拖累。

常见失误：把均值和中位数的增长率混为一谈。

Q5. 【综合 5】为什么说 (dW_t)² = dt 是连接随机过程和二阶欧拉方程的桥梁？
展开参考答案与解析

参考答案：因为展开 dV(X_t) 的二阶 Taylor 项时，(dX_t)² = σ² X_t² (dW_t)² = σ² X_t² dt 不会消失，从而直接产生 ODE 里的 ½σ²x²V'' 项。

解析：RO-S06 与 Stage 2 Itô 引理的核心衔接。

常见失误：把随机微积分当成普通微积分直接忽略二阶项。
