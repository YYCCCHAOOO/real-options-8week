连续折现、无穷积分与现值算子：把现金流变成解析公式

1. 3 分钟直觉唤醒（一句话核心）

连续时间里，把未来每秒流进来的现金流乘上折现因子 e^{-rt} 再从 0 积到无穷，就得到永续现金流的现值公式 x / (r - μ)。

它解决什么建模痛点：实物期权里一旦决定投资，你将立刻拿到“未来无穷期现金流的期望现值”（比如 v_R(x) 或 v_C(x)）。理解连续折现积分和无穷远横截条件，你就能一眼看懂已建成项目的价值公式是怎么来的。

课程衔接：RO-S03 解决了“等待期”的齐次 ODE；本课解决“投产后”的非齐次特解与现金流现值。

2. 10 分钟核心公式与白话拆解

离散时间里，1 年后收到 1 块钱折现到今天是 1/(1+r)；如果把计息频率拆成每秒、每毫秒无限细分，连续复利折现因子就是 e^{-rt}。

假设项目建成后，t 时刻的期望现金流以速率 μ 增长，即 E[X_t] = x e^{μt}。把它折现到今天再把从 t=0 到 t=∞ 的每一瞬间加起来，就是积分 ∫_0^∞ x e^{-(r-μ)t} dt。

只要 r > μ，被积函数指数衰减，积分收敛并给出极其干净的结果：x / (r - μ)。这就是金融学里著名的连续时间 Gordon 增长公式——同时也是非齐次 ODE (1/2)σ²x²v'' + μxv' - rv + x = 0 的特解！

连续折现永续现金流现值
$$v(x) = \mathbb{E}_x\left[\int_0^\infty e^{-rt} X_t \, dt\right] = \int_0^\infty e^{-rt} x e^{\mu t} \, dt = \frac{x}{r - \mu} \quad (r > \mu)$$

白话读法：当现金流期望按 μ 增长、按 r 折现时，永续现值等于当前流量 x 除以净折现率 (r - μ)。

非齐次欧拉方程 = 特解（永续现金流）+ 齐次通解（期权/边界调整）
$$\frac{1}{2}\sigma^2 x^2 v'' + \mu x v' - r v + x = 0 \implies v(x) = \frac{x}{r - \mu} + A x^\beta + B x^\alpha$$

白话读法：已建成但带有未来调整权（如暂停、退出或保底补贴）的项目价值，天然拆成“永久持有基准现值 x/(r-μ)”加上“附加期权项 A x^β + B x^α”。

第 1 步：计算指数无穷积分

∫_0^T e^{-kt} dt = (1 - e^{-kT}) / k。当 k = r - μ > 0 且 T → ∞ 时，e^{-kT} → 0，得到 1/k = 1/(r - μ)。

实战口诀：记住最常用的积分模板：∫_0^∞ e^{-kt} dt = 1/k（k > 0）。
适用边界：若 k ≤ 0（即 r ≤ μ），积分发散到 +∞，现值不存在。

第 2 步：把“期望与积分交换顺序”当成标准动作（Fubini/Tonelli）

因为 X_t > 0，非负随机过程允许直接把期望 E 放进积分号里面，只需知道 E[X_t] = x e^{μt} 就能算出期望现值，甚至不需要知道 X_t 的完整分布。

实战口诀：线性现金流求期望现值，先算 E[X_t] 再积分。
适用边界：如果现金流是非线性的（例如带下限 max(X_t, F)），不能把期望直接塞进 max 里面，必须用 ODE 或分布积分求解。

第 3 步：验证特解代入非齐次 ODE

把 v_p(x) = x/(r-μ) 代入 (1/2)σ²x²v'' + μxv' - rv + x：二阶导为 0，一阶导为 1/(r-μ)，于是 μx/(r-μ) - rx/(r-μ) + x = -x + x = 0，精确成立！

实战口诀：看到非齐次项是线性现金流 x 或常数 c，特解分别试 x/(r-μ) 和 c/r。
适用边界：若是非线性现金流 x^k，则特解为 x^k / (-Q(k))，要求 Q(k) < 0。

3. 5 分钟最小算例（教学演示）

【教学演示】拆解一个带固定运维成本的已建项目现值

（教学演示算例）假设电厂建成后每秒净现金流为 X_t - c（当前 X_0 = 10，固定运维费 c = 2，r = 0.06，μ = 0.02）。

  1. 收入流 X_t 的永续现值：10 / (0.06 - 0.02) = 250。
  2. 固定成本流 c 的永续现值：2 / 0.06 ≈ 33.33（注意固定成本不随 μ 增长，所以除以 r 而不是 r - μ）。
  3. 若没有任何退出或保底条款，项目价值就是 250 - 33.33 = 216.67；若允许未来在 X_t 太低时关闭电厂，则会额外多出一项放弃期权 B x^α > 0。

4. 3 分钟防坑边界与常见误区

顶刊与推导避坑提示
  • 把固定成本 c 也错误地除以 (r - μ)：常数现金流没有增长率 μ，它的永续现值永远是 c / r。
  • 遇到带下限保证 max(X_t, F) 的现金流，误写成 max(E[X_t], F) 再积分：由 Jensen 不等式，E[max(X_t, F)] > max(E[X_t], F)，直接交换会系统性低估保底条款的价值。

5. 5 分钟轻量自测与 60 秒费曼复述

Q1. 现金流为常数 c 的永续现值是多少？为什么分母不是 r - μ？
展开参考答案与解析

参考答案：c / r。因为常数现金流不随随机过程 X_t 增长，它的增长率是 0。

解析：∫_0^∞ c e^{-rt} dt = c / r。

常见失误：受 x/(r-μ) 惯性影响，把常数项也写成 c/(r-μ)。

Q2. 为什么在已建项目带有“价格跌破 F 时享受补贴”的条款后，其价值函数会写成 x/(r-μ) + B x^α（在 x > F 区域）？
展开参考答案与解析

参考答案：x/(r-μ) 是无补贴时的永续现金流特解，B x^α（α < 0）代表未来价格跌破 F 触发补贴的期望折现期权价值，且当 x → ∞ 时触发补贴的概率趋于 0，因此不包含 A x^β 项。

解析：这正是“基准现值 + 边界期权调整”的标准物理拆解。

常见失误：看不懂为什么已建成项目里也会出现幂函数 x^α。

Q3. 若项目建成后现金流为 X_t - c，且满足 r > μ > 0，求非齐次方程 (1/2)σ²x²v'' + μxv' - rv + (x - c) = 0 的一个特解。
展开参考答案与解析

参考答案：v_p(x) = x/(r - μ) - c/r。

解析：线性微分方程满足叠加原理，两项的特解直接相加即可。

常见失误：把负号写反或把 c/r 错写成 c/(r-μ)。
